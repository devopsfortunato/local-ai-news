NVIDIA's TensorRT Edge-LLM unifies DGX Spark-to-Jetson Thor inference in a few commands

TensorRT Edge-LLM 0.11.1 ships with the new trtedge CLI on the 64GB DGX Spark: a few commands download a model, build a TensorRT engine and serve Nemotron-3.5 Lightning through an OpenAI-compatible API, and the same runtime deploys unchanged to Jetson Thor, DRIVE AGX Thor and IGX Thor. With DSpark speculative decoding, mean generation rises from 73.4 to 126.9 tokens/s on HumanEval prompts at 27.9GB peak system memory. For local-AI operators it points to one dev-to-edge stack instead of a separate embedded pipeline.
