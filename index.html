DGX Spark

NVIDIA opens DGX Spark to eight-unit clusters with 1TB of pooled unified memory

At GTC Berlin, NVIDIA enabled manual clustering of up to eight DGX Spark GB10 units over ConnectX-7, pooling as much as 1TB of unified memory — enough to run frontier-class open models like GLM 5.3 on a desk. The 64GB DGX Spark ($4,999) ships from Acer, ASUS, Dell, GIGABYTE, HP and MSI on Friday, October 23, while the 128GB model has climbed to $6,950 amid the memory crunch. NVIDIA also announced llama.cpp and vLLM optimizations — up to 1.4x faster agentic tasks on RTX PRO 6000 — plus day-zero support for Nemotron, GLM, DeepSeek, Qwen, MiniMax and FLUX.3 and a new FP4 checkpoint collection.
