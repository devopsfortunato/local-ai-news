Open-source UEFI tool unlocks Nvidia's half-speed tensor limiter on RTX 20/30/40 cards

The nv-uefi-unlocker project boots from a USB drive before the Nvidia driver loads and removes the half-speed Tensor Core throttle on RTX 20, 30 and 40 series desktop and laptop GPUs, lifting FP16 matrix math performance by up to 65% on Windows and Linux. Blackwell RTX 50 series is not covered. It is free throughput for the huge installed base of last-gen cards powering local LLM rigs.

Hugging Face blog: ViKernel wires an operating system inside the model file

ViKernel / VIDRAFT is a weight-native OS design that puts ROM, RAM and an xPU-style control circuit directly into the model file, with an in-model kill switch, boot integrity state and a non-editable audit chain instead of external wrappers and prompt filters. A public demo is available at FINAL-Bench/ViKernel-Desktop.

llama.cpp b12034 lands with WebGPU scratch-allocation fix and new OpenCL IQ3 support

The Nov 2 build keeps scratch allocation sizes monotonic in batch length for the flash-attention vec and MMVQ paths. The Nov 1 batch (b12029-b12032) added initial IQ3 OpenCL support, a PkgConfig path for LevelZero SYCL includes and a Hexagon DMA stride fix.

An aggregated measurement table shows the DGX Spark at ~59 tok/s on gpt-oss-120b at low context in llama.cpp, with dense 70B models under 5 tok/s; software updates moved scores more than partner-board differences. Two clustered 64GB units reach up to 1.7x single-unit performance via NVIDIA Sync.
