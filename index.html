Milestone Release

llama.cpp hits v1.0.0 with a stable-API promise

The default inference engine of the local-AI world committed to semantic versioning on Nov 13, retiring 35 deprecated functions and reserving breaking C-API/ABI changes for major-version bumps. The release adds FP8 KV caches, a host-memory MoE expert cache, new architectures (Kimi-K3.1-Pro, Ripple, xing4_0), drama-3 TTS with a /v1/audio/speech endpoint, a hardened llama-server (SSRF, CORS, DNS-rebinding defenses, MCP tool cancellation), a redesigned web UI, a native macOS app, and official Docker, Debian, Homebrew, conda-forge, MacPorts, Winget and XCFramework channels. The r/LocalLLaMA announcement drew roughly 1,500 upvotes in a day.
